# دليل النشر الموزع لسرب NSM (Distributed Deployment Guide)

يعد تحويل **Neural Service Mesh (NSM)** إلى نظام موزع حقيقي خطوة جوهرية نحو تحقيق السيادة الكاملة واللامركزية. يوضح هذا الدليل كيفية تشغيل العقد على خوادم مستقلة وتأمين التواصل بينها.

## 1. المتطلبات الأساسية
لتشغيل عقدة موزعة، يجب توفر ما يلي على كل خادم:
*   **بيئة Python 3.10+** مع تثبيت المكتبات اللازمة (`websockets`, `cryptography`, `numpy`).
*   **عنوان IP عام (Public IP)** أو إمكانية الوصول عبر الشبكة.
*   **فتح المنفذ (Port Forwarding)**: يجب السماح بمرور حركة البيانات عبر المنفذ المستخدم (افتراضياً `8765`).

## 2. تشغيل العقدة الأولى (Seed Node)
العقدة الأولى تعمل كـ "بذرة" لتكتشفها باقي العقد. قم بتشغيلها باستخدام الأمر التالي:

```bash
python3 ai/node_launcher.py --id mesh_alpha --host 0.0.0.0 --port 8765 --public-ip [YOUR_SERVER_IP]
```

## 3. انضمام العقد الإضافية
بمجرد تشغيل العقدة الأولى، يمكن لباقي العقد الانضمام للشبكة عبر الإشارة إليها:

```bash
python3 ai/node_launcher.py --id mesh_zeta --host 0.0.0.0 --port 8766 --seed-host [SEED_SERVER_IP] --seed-port 8765 --public-ip [CURRENT_SERVER_IP]
```

## 4. جدول إعدادات الشبكة

| المعامل | الوصف | مثال |
| :--- | :--- | :--- |
| `--id` | معرف فريد للعقدة في الشبكة. | `mesh_omega` |
| `--host` | عنوان الـ IP الذي يستمع عليه الخادم محلياً. | `0.0.0.0` |
| `--port` | المنفذ المخصص لاستقبال اتصالات WebSockets. | `8765` |
| `--seed-host` | عنوان IP لعقدة البداية (للانضمام للشبكة). | `1.2.3.4` |
| `--public-ip` | العنوان الخارجي الذي سيراه الآخرون للوصول إليك. | `5.6.7.8` |

## 5. اعتبارات الأمان والسيادة
*   **الهوية الرقمية**: كل عقدة تقوم بتوليد زوج مفاتيح RSA عند التشغيل الأول. تأكد من الاحتفاظ بملفات المفاتيح في `artifacts/living_mesh/keys/` لتجنب تغيير هوية العقدة عند إعادة التشغيل.
*   **التشفير**: جميع الاتصالات عبر WebSockets مشفرة وموقعة رقمياً. لا تقبل الشبكة أي خبرات من عقد غير مسجلة مفاتيحها العامة مسبقاً أو عبر بروتوكول الاكتشاف الآمن.
*   **جدار الحماية**: يوصى بتقييد الوصول إلى منفذ العقدة ليقتصر على عناوين IP المعروفة للأقران إذا كانت الشبكة خاصة، أو تركه مفتوحاً إذا كانت الشبكة عالمية (Public Mesh).

> **ملاحظة**: عند التشغيل خلف NAT أو Router، تأكد من إعداد Port Forwarding للمنفذ المختار لضمان قدرة الأقران على الوصول إلى خادم WebSocket الخاص بك.
