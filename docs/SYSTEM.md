# NSM — نظرة على النظام ككل

Neural Service Mesh طبقات مترابطة:

```
المستخدم (Streamlit / أوامر نصية)
        │
        ▼
agent_user_assist  →  system_hub (نبض شامل)
        │
        ▼
agent_project_bridge
   ├─ agent_growth_loop   (خطة · تنفيذ آمن · ذاكرة)
   ├─ model_training_agent (معاينة · تنفيذ · سجل مهام)
   ├─ hierarchical MoE + moe_ckg_bridge
   └─ reasoning_pipeline (شريط توجيه MoE في الإجابة)
        │
        ▼
CKG / ذاكرة / واجهات ui_pages
```

## أوامر مركزية
| أمر | الوظيفة |
|-----|---------|
| `تقرير النظام` | صحة شاملة |
| `مساعدة` | قدرات الوكيل |
| `صنّف: ...` | توجيه MoE |
| `مهمة تدريب ...` | خطة تدريب (أضف `نفّذ` للتشغيل) |
| `نفّذ بأمان: ...` | أدوات آمنة فقط |

## واجهات
- **🧩 MoE والوكيل** — تصنيف ونمو
- **🎯 الوكيل الموحّد** — مدير المحادثة
- **🏥 صحة النظام** — يتضمن System Hub
