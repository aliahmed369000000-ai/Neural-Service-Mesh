# جرد قدرات الوكيل (Agent Capabilities Inventory)
## نظام Neural Service Mesh (NSM)

تم إجراء فحص شامل للمحركات المتاحة في مجلد `ai/` لتحديد الإمكانيات الحالية للوكلاء في التعامل مع الوسائط المتعددة والبيئات المعزولة.

### 1. بيئة الساندبوكس (Sandbox)
- **المحرك:** `ai/sandbox_lab.py`
- **الحالة:** **موجود ومفعل.**
- **الوظيفة:** يوفر بيئة معزولة لاختبار الكود المولد آلياً قبل اعتماده. يقوم بفحص:
    - صحة البناء (Syntax).
    - نجاح الاستيراد (Import).
    - سلامة التنفيذ (Execution).
    - معايير الأمان (Safety Score).

### 2. قدرات الصوت (Audio)
- **المحرك:** `ai/stt_engine.py` و `ai/tts_engine.py`
- **الحالة:** **موجود ومفعل.**
- **الإمكانيات:**
    - **STT:** تحويل الصوت إلى نص باستخدام Gemini 2.5 Flash مع دعم خاص للهجة اليمنية.
    - **TTS:** تحويل النص إلى كلام (لم يتم فحص التفاصيل لكن المحرك موجود).

### 3. قدرات الصور (Images)
- **المحرك:** `ai/image_search_tool.py`
- **الحالة:** **موجود ومفعل.**
- **الوظيفة:** البحث عن صور حقيقية وعالية الجودة عبر Unsplash API.

### 4. قدرات الفيديو (Video)
- **المحرك:** `ai/video_engine.py`
- **الحالة:** **موجود (حجم كبير 108KB).**
- **الملاحظة:** المحرك ضخم جداً مما يوحي بقدرات معالجة أو توليد فيديو متقدمة.

### 5. التعامل مع الملفات
- **الحالة:** **موجود عبر الأدوات الأساسية.**
- **الوظيفة:** الوكيل يمتلك حالياً أدوات `read_file` و `write_file` و `find_files`.

---
**النتيجة:** الوكيل يمتلك بنية تحتية قوية جداً للوسائط المتعددة، لكنها غير مرتبطة بـ `TOOL_REGISTRY` في `agent_loop.py` بشكل مباشر حتى الآن.
