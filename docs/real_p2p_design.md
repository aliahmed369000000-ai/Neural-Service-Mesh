# تصميم بروتوكول التواصل الحقيقي (Real P2P Communication Design)

## 1. المفهوم العام
يهدف هذا التصوير إلى تحويل العقد من مجرد سجلات في ملف JSON إلى **خوادم نشطة** تتحدث مع بعضها البعض عبر شبكة TCP. سيتم استخدام مكتبة `asyncio` في Python لضمان المعالجة غير المتزامنة لآلاف الرسائل.

## 2. المعمارية التقنية

### أ. خادم الاستماع (Node Listener)
كل عقدة ستقوم بفتح منفذ (Port) خاص بها للاستماع للخبرات القادمة.
*   **البروتوكول**: TCP (أو WebSockets لاحقاً).
*   **تنسيق البيانات**: JSON مشفر.

### ب. عميل الإرسال (Node Client)
عندما تريد العقدة مشاركة خبرة، ستقوم بالاتصال المباشر بعنوان الـ IP والمنفذ الخاص بالعقدة المستهدفة.

## 3. تدفق البيانات (Data Flow)
1.  **اكتشاف الأقران (Discovery)**: العقدة تقرأ قائمة الأقران وعناوينهم من `network_state.json`.
2.  **المصافحة (Handshake)**: العقدة "أ" تتصل بالعقدة "ب" وتؤكد هويتها الرقمية.
3.  **تبادل الخبرات (Experience Exchange)**: إرسال بيانات الخبرة (kind, data, timestamp).
4.  **تحديث الأوزان (Weight Sync)**: العقدة المستلمة تقوم بتحديث أوزانها السلوكية فوراً.

## 4. المزايا المتوقعة
*   **السرعة**: تواصل لحظي دون الحاجة لانتظار دورة كتابة الملف.
*   **الاستقلالية**: إذا تعطل الخادم المركزي، تستمر العقد في التحدث مع بعضها البعض.
*   **الواقعية**: محاكاة حقيقية لبيئة الإنتاج الموزعة.
